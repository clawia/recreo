# `docs/adr/` — miroir humain

Les ADR **canoniques** de `recreo` vivent dans
[`squad/decisions/adr/`](../../squad/decisions/adr/) (`ADR-XXXX-<slug>.md` + `ADR-index.md`),
tenus par `theo-archi`. C'est la **source de vérité unique**.

`docs/adr/` n'est qu'un **miroir humain optionnel** : un point d'entrée pratique pour qui
explore `docs/` sans connaître l'organisation de `squad/`. En cas de divergence entre les deux,
`squad/decisions/adr/` fait foi.

Pour consulter les ADR à jour : voir
[`squad/decisions/adr/ADR-index.md`](../../squad/decisions/adr/ADR-index.md).
