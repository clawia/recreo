la seule image qui n'est pas un choix (`M2`). Un enfant de CP lit ce qui est sous l'image : *"la reference est fausse"*.
140 px de blanc ne defont pas un code que le jeu lui apprend lui-meme a chaque erreur.

**Ce que j'accepte** : le message en deux colonnes, **si le signal et son texte sont places sous le meuble, dans sa
largeur**, et jamais sous la reference seule. Le point 1 de `lecture-nadia-palier-1.md` 1.4 reste tenu : le message est
sous le meuble, jamais au-dessus, et la reference reste visible a cote. La forme (largeurs des colonnes, bandeau unique sur les deux colonnes ou signal seul colore) est a
`ines-design`. **Ce que cela peut couter, dit d'avance** : dans 496 px au lieu de 696, la phrase de la revelation peut
