# [Sprint s06] Planning — 2026-07-19

- Sprint : s06 ; animé par Sofia ; présents : Camille, Marc, Léa, Théo, Yanis.

## Objectif de sprint
Introduire la **2e mécanique** de la bibliothèque : **Texte à trous** (compléter un mot manquant),
et prouver que l'architecture supporte **plusieurs mécaniques** proprement. Gros gain de couverture
en français CM1 (conjugaison, accords).

## Enjeu d'architecture (Théo) — ADR-0007 pressenti : « support multi-mécaniques »
- **Sélection de mécanique par entrée de catalogue** : `GameCatalog.mechanicFor(mechanicId)` existe
  déjà (prévu depuis s01) → enregistrer **2 mécaniques** (bandit manchot + texte à trous) ; chaque
  entrée de catalogue référence sa mécanique.
- **Logique de session partagée sans couplage entre mécaniques** : la logique commune (score,
  `answered`, `masteredKeys`, cible, item suivant en excluant les réussis, fin de session) est
  extraite dans **`domain/mechanic`** (paquet parent partagé), PAS dans un paquet `mechanics.*`.
  Les deux mécaniques y délèguent. **La règle ArchUnit 5 (mécaniques isolées entre elles) doit
  rester verte** : `mechanics.banditmanchot` et `mechanics.texteatrou` ne se référencent jamais.
- **Sélection de la vue selon la mécanique** : le view-model porte un identifiant de vue ; la page
  de jeu insère le bon fragment (`fragments/banditmanchot` ou `fragments/texteatrou`). Les éléments
  communs (score, emplacement message, écran de fin) sont mutualisés dans un fragment commun.
- Réutilise le **mode session** (ADR-0006) et les **réglages** (« nombre de questions », ADR-0005).

## Story

### US-s06 — Mécanique « Texte à trous » + 3-4 jeux
> En tant qu'élève, je complète le mot manquant d'une phrase/égalité en choisissant parmi des mots.

Critères d'acceptation :
- [ ] Nouvelle mécanique `TexteATrouMechanic` (`domain/mechanics/texteatrou`), id `TEXTE_A_TROU`,
      **isolée** de bandit manchot (ArchUnit 5 verte), logique de session **partagée** via
      `domain/mechanic`.
- [ ] Présentation distincte : la **phrase avec un trou** (`___`) est affichée ; l'enfant choisit le
      mot parmi des options (bandit-manchot = machine à sous ; texte à trous = phrase à compléter).
- [ ] Jeux livrés (contenus vérifiés, réutilisent le modèle `Item`) :
      - `conjugaison-cm1` (Français CM1) — présent de l'indicatif ;
      - `accords-cm1` (Français CM1) — accord de l'adjectif ;
      - `mot-manquant-cp` (Français CP) — compléter une phrase (sens) ;
      - `egalite-cp` (Maths CP) — compléter une égalité (ex. `3 + ___ = 10`).
- [ ] Chaque jeu apparaît dans les deux axes de navigation, avec réglage « nombre de questions » et
      écran de fin (mode session), comme les autres.
- [ ] `mvn verify` vert (tests + **5 règles ArchUnit**).
