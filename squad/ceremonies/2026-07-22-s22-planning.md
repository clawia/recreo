# [Sprint s22] Planning — 2026-07-22

- Sprint : s22 ; animé par Sofia ; présents : toute la squad.
- Horodatage début : 2026-07-22 (enchaîné après s21). Direction : **deux livrables** — une évolution
  d'**ergonomie** (filtres de la liste « Par jeu », roadmap §E / IDEE-3) et une **8e mécanique**
  (droite graduée, roadmap §B).

## Objectif de sprint
1. **Filtres « Par jeu »** (backlog **IDEE-3** / roadmap §E) — l'écran `/jeux` (liste plate de tous
   les jeux) devient **filtrable** par **niveau** (CP / CM1) et par **matière** grâce à des **boutons**,
   filtres **combinables** et **réinitialisables**. **Filtrage serveur par query params**
   (`/jeux?niveau=&matiere=`), pur **read-model / vue**, **aucun changement de domaine**. **Pas d'ADR.**
2. **8e mécanique « Droite graduée »** (roadmap §B / DEC-0019 / ADR-0018) — l'enfant **place un nombre
   sur une droite graduée 0 → N** en **cliquant la bonne graduation**. **Réutilise le coup
   `SpinAndPick`** du bandit manchot (aucun nouveau coup — comme puzzle réutilise `SubmitArrangement`,
   memory `SubmitAssociations`). **Jokers automatiques** (tick faux = cœur perdu + tick grisé).
   Générateur **combinatoire** `DroiteGradueeGenerator` (bornes câblées dans `BeansConfig`) ; 2 jeux
   `droite-graduee-cp` (0 → 20) et `droite-graduee-cm1` (0 → 100) ; îlot JS de vue `droitegraduee`.

## US-s22
- **Domaine** : **aucun nouveau coup** — droite graduée réutilise `SpinAndPick` (paquet partagé
  `domain.mechanic`) ; mécanique isolée `mechanics/droitegraduee`. Filtres « Par jeu » : **read-model
  pur** (aucun impact domaine).
- **Bootstrap** : `DroiteGradueeGenerator` combinatoire câblé dans `BeansConfig` (bornes 0→20 /
  0→100) + 2 entrées catalogue (`droite-graduee-cp`, `droite-graduee-cm1`). Pas de YAML (contenu
  combinatoire).
- **Web** : îlot JS de vue `droitegraduee` (droite + clic de graduation + tick grisé) ; barre de
  filtres sur `/jeux` + gestion des query params `?niveau=&matiere=` (filtrage serveur).
- **ArchUnit** : **une seule nouvelle décision d'archi (ADR-0018, droite graduée)** — l'isolation en
  slices dynamiques `slices().matching("com.recreo.domain.mechanics.(*)..")` couvre
  **automatiquement** le nouveau paquet `mechanics.droitegraduee`. Objectif **5/5 vertes**.
