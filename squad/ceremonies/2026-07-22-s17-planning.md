## Objectif de sprint
Gros incrément unique couvrant la roadmap **A1 + A2 + B** :
1. **Jokers / 3 cœurs (transverse)** — sur une erreur, on **retente le même item** (pas d'avance) ;
   **3 cœurs** par session, chaque erreur consomme 1 cœur ; à **0 cœur**, une erreur **termine** la
   session. Sur un jeu à clic, l'option fausse cliquée devient non cliquable. Cœur consommé **par clic
   faux** ; bonne réponse après retente = **+10 plein** (cf. DEC-0013).
2. **5e mécanique « Associer / Classer »** — coup générique `SubmitAssociations(Map)` (1er coup
   d'appariement/catégorisation au-delà de l'ordonnancement). 2 jeux YAML : `anglais-associer-cm1`,
   `vivant-non-vivant-cp` (cf. ADR-0016 / DEC-0014).
3. **6e mécanique « Memory »** — cartes retournées (îlot JS flip), réutilise `SubmitAssociations`.
   4 jeux YAML : `memory-quantite-cp`, `memory-fraction-cm1`, `memory-anglais-cm1`, `memory-mot-image-cp`.

## US-s17
