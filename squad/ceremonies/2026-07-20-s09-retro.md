# [Sprint s09] Rétro — 2026-07-20

- Sprint : s09 ; animé par Sofia ; présents : toute la squad.

## Ce qui a bien marché
- **Refactor sans régression** : externaliser 7 jeux en préservant entryId/gameKey/titres/questions
  → tous les tests de navigation/paramètres restent verts sans y toucher. Le contrat de catalogue
  a servi de filet.
- **Bon découpage** : commencer par les quiz (déjà une simple liste) a rendu la 1re tranche propre
  et rapide ; le pattern (loader en bootstrap + validation + scan classpath) est posé pour la suite.
- **Valeur produit tangible** : l'utilisatrice peut désormais éditer/ajouter un quiz sans dev ;
  guide fourni.

## Ce qui a moins bien marché / vigilance
- **Transcription Java → YAML** : risque d'erreur de recopie du contenu ; mitigé par les tests de
  tailles de viviers + invariants, mais une relecture humaine du contenu reste utile.
- **Édition YAML par un non-dev** : indentation sensible. Mitigé par la validation au démarrage
  (message clair) et l'en-tête d'aide dans chaque fichier ; à surveiller au premier usage réel.

  gardant le loader en bootstrap, comme le calcul mental. L'abstraction tenait déjà (QuizGenerator

- **Marc (dev)** : « Sept sous-classes quasi identiques remplacées par un générateur + des fichiers :
